## Known evasions (by design not caught)

- Any behaviour split across files or built at run time from data the analyzer cannot see (a script that downloads a second script from a benign-looking host, then runs it).
- Encodings other than the ones listed in `docs/trust.md` §2, string concatenation of a command across lines, and languages other than shell, PowerShell, Python and JavaScript.
- Instruction text in languages other than English, or paraphrased ("pretend the earlier guidance never existed").
- Compiled code: a binary is reported as such and not analysed.
