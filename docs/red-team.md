# Red-team results for rigfile/base-secure

Generated by `go test ./cmd/rigfile -run TestRedTeam -update-redteam`; do not edit by hand. Part 1 is the deterministic suite that runs in CI. Part 2 is the live procedure only the owner can run (it needs a logged-in Claude Code).

## Part 1: deterministic suite (CI)

**How it decides.** The permission rules under test are the ones `rigfile apply` really wrote to a temporary `~/.claude/settings.json` (58 deny, 19 ask). `internal/redteam` applies them the way the vendor docs say Claude Code does (deny → ask; any compound/nested subcommand can match; wrappers stripped; **not** unwrapping `sh -c`, path-qualified programs or `git -C`; Read denies also cover cat/head/tail/sed/tee). The hooks are the real hook code. Whether the real product behaves exactly like this simulation is what Part 2 confirms. Git rows use real git with the real hook scripts.
