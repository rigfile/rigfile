Rigfile rigs bundle instructions, skills, MCP servers, hooks and permissions for Claude Code, Codex, Gemini CLI and Cursor. Pull one with a single command; secrets never travel with a rig.

rigfile pull owner/name --registry {{.Data.RegistryURL}}

Quickstart

No packaged builds yet — build the CLI from source (needs Go).

  1. Get the CLI.

    git clone https://github.com/rigfile/rigfile
cd rigfile && go build -o rigfile ./cmd/rigfile

  2. Capture your current Claude Code setup into a rig (read-only — nothing changes yet).

    ./rigfile init

  3. Review the plan, then apply it. Nothing runs until you approve.

    ./rigfile plan rig
./rigfile apply rig

  4. Share it — private by default, or add --public.

    ./rigfile publish rig --to-registry --registry {{.Data.RegistryURL}}
