How it works

  1. CaptureTurn the setup you already have into a rig: rigfile init reads it, changes nothing.
  2. Reviewrigfile plan shows every file, hook, server and permission a rig would change, before anything runs.
  3. Applyrigfile apply writes it with a backup first. rigfile rollback undoes any run.
  4. Sharerigfile publish --to-registry scrubs personal paths, blocks secrets and scans before anyone can pull it.

Quickstart

  1. Build the CLI from source (needs Go; packaged releases are coming).

    git clone https://github.com/rigfile/rigfile
cd rigfile && go build -o rigfile ./cmd/rigfile

  2. Capture your current Claude Code setup into a rig named after your GitHub login (the registry only accepts rigs under your own name). Read-only: nothing changes yet.

    ./rigfile init --name your-login/my-rig

  3. Review the plan, then apply it. Nothing runs until you approve.

    ./rigfile plan rig
./rigfile apply rig

  4. Share it: private by default, add --public to let anyone pull it.

    ./rigfile login --registry {{.Data.RegistryURL}}
./rigfile publish rig --to-registry --registry {{.Data.RegistryURL}}
